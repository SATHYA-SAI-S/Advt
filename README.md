## 1. Project Overview

Traditional Multi-Touch Attribution (MTA) models—such as First-Touch, Last-Touch, Linear, and standard observational regressions—frequently mistake correlation for causation. High-intent consumers naturally encounter retargeting ads right before purchasing, leading naive models to attribute immense value to retargeting while undervaluing prospecting channels that generated that intent.

**Decision-Stable Causal Attribution (DSCA)** solves this confounding problem with a complete causal inference and robust decision engine:
1. **Cross-Fitted AIPW (Doubly Robust Estimation)**: Estimates channel-level Average Treatment Effects (ATE) using machine learning for both propensity scores and outcome regressions with 5-fold cross-fitting and Neyman-orthogonal scores.
2. **Positivity & Overlap Diagnostics**: Computes extreme propensity shares, Effective Sample Size (ESS), propensity distributions, and post-weighting Standardized Mean Differences (SMD) across all baseline covariates.
3. **Marginal Sensitivity Model (MSM) Bounds**: Computes sharp upper and lower ATE bounds under Rosenbaum/Tan-style unobserved confounding for sensitivity parameters $\Gamma \in [1.0, 3.0]$.
4. **Decision-Stability Classification**: Identifies the exact breakdown point $\Gamma^*$ where channel profitability reverses sign, classifying channels into `stable`, `fragile`, or `unidentifiable`.
5. **Minimax Regret Budget Optimization**: Allocates advertising capital under worst-case sensitivity bounds, preventing catastrophic misallocation when unobserved confounders are present.
6. **Value of Information (VOI) Experiment Selector**: Recommends targeted A/B test experiments on the most fragile channels by quantifying regret reduction against experiment implementation costs.

## 4. Cross-Platform Quickstart (macOS & Windows)

The backend is built with strict OS independence:
- Paths are managed strictly with Python's standard `pathlib.Path`.
- Line endings are normalized to standard LF via `.gitattributes`.
- Text encodings are enforced as UTF-8.

### Prerequisites
- Python **3.12** (recommended: standard `python.org`, `pyenv`, or `brew install python@3.12`)
- Git

### Installation

#### On macOS / Linux
```bash
# Clone the repository
git clone https://github.com/SATHYA-SAI-S/Advt.git
cd Advt

# Create and activate virtual environment
python3.12 -m venv .venv
source .venv/bin/activate

# Upgrade pip and install package with dev dependencies
pip install --upgrade pip
pip install -e ".[dev]"
```

#### On Windows (PowerShell)
```powershell
# Clone the repository
git clone https://github.com/SATHYA-SAI-S/Advt.git
cd Advt

# Create and activate virtual environment
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1

# Upgrade pip and install package with dev dependencies
python -m pip install --upgrade pip
```

## 5. CLI Usage & Commands

The CLI can be invoked either directly via `dsca` (when installed in editable mode) or via `python -m decision_stable_causal_attribution.cli`:

### 1. Run Synthetic Simulation Pipeline
Runs the end-to-end benchmark on synthetic data with configurable confounding:
```bash
# Available scenarios:
# unconfounded, moderate_confounding, strong_confounding, severe_positivity_violation
python -m decision_stable_causal_attribution.cli simulate \
    --scenario moderate_confounding \
    --population 5000 \
    --budget 10000 \
    --output results/research_result.json
```

### 2. Download GA4 Observational Cohort from BigQuery
Extracts the 30-day first-visit ecommerce cohort (Nov 1 – Dec 31, 2020) from Google Analytics 4 public dataset:
```bash
python -m decision_stable_causal_attribution.cli download-ga4 \
    --project <YOUR_GCP_PROJECT_ID> \
    --output data/processed/ga4_cohort.parquet
```

### 3. Run Pipeline on Extracted GA4 Dataset
Estimates causal attribution and robustness profiles on GA4 observational data:
```bash
python -m decision_stable_causal_attribution.cli run-ga4 \
    --input data/processed/ga4_cohort.parquet \
    --max-records 10000 \
    --budget 10000 \
    --output results/ga4_research_result.json
```

### 4. Run Pipeline on Criteo Uplift Benchmark
Evaluates AIPW against randomized controlled trial (RCT) ground truth from the Criteo Uplift v2.1 benchmark:
```bash
python -m decision_stable_causal_attribution.cli run-criteo \
    --input data/raw/criteo-uplift-v2.1.csv.gz \
    --sample-size 20000 \
    --budget 10000 \
    --output results/criteo_research_result.json
```

### 5. Multi-Scenario Batch Evaluation
Runs all four core synthetic scenarios sequentially and outputs a unified benchmark report:
```bash
python -m decision_stable_causal_attribution.cli evaluate-all \
    --n 3000 \
    --budget 10000
```
